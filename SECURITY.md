# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. That opens a report only the maintainers can see.

Include what you found, how to reproduce it, and which package and version it affects. We will reply in the report.

## Scope

This covers the code in this repository: the SDKs published from it. For a vulnerability in Cimento itself, use the same route and say so in the report.
